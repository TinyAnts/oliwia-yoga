# Oliwia Konieczna — Yoga

Portfolio site for Oliwia Konieczna, RYT-200 Yoga Alliance certified yoga instructor (Ashtanga, Vinyasa, Yin, Yoga Nidra, Healthy Spine & Stretching).

Vite + React + Tailwind CSS v4. Fully static.

## Develop
```bash
npm install
npm run dev
npm run build   # -> dist/
```

## Deploy
Cloudflare Pages, auto-deploys from `main`. Build: `npm run build`, output: `dist`.
Custom domain: yoga.oliwiakonieczna.info

## Content
Everything lives in `src/pages/Home.tsx` (classes, certifications, socials, CONTACT_EMAIL). Photos in `src/assets/images/`.
